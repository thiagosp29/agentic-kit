# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, aceite críticas construtivas e foque no que é melhor para a comunidade. Assédio, ataques pessoais e linguagem discriminatória não são tolerados.

Para relatar um comportamento inaceitável, entre em contato com o mantenedor de forma privada pelo perfil [@thiagosp29](https://github.com/thiagosp29). Todos os relatos são tratados com sigilo.
