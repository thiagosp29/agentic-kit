# Política de segurança

## Versões suportadas

Apenas a versão mais recente publicada recebe correções.

## Como relatar uma vulnerabilidade

**Não abra issue pública.** Use o [relato privado de vulnerabilidades](https://github.com/thiagosp29/agentic-kit/security/advisories/new) do GitHub.

Inclua o que for possível: passos para reproduzir, impacto e versão afetada. A resposta inicial deve vir em até 7 dias.

## O que conta como vulnerabilidade

Além de falhas na CLI (por exemplo, escrita fora do diretório de destino), também contam itens do kit que induzam a IA a executar ações perigosas: instruções escondidas, comandos destrutivos, exfiltração de dados ou desativação de salvaguardas.
